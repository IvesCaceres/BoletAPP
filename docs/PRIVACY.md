# Privacy boundary

Original reports/boletas, individual taxpayer records, real RUTs and personal contacts confirmed in the old history, populated databases, credentials and authenticated browser states are excluded. Private operational files remain in the unchanged source project and a separately restricted backup.

Demo/test records are fictional. Positive RUT-validation examples are generated for offline validation; a valid checksum is not proof of global nonassignment. Never submit fixtures to SII. No browser session or client import data are distributed.

The source candidate is an explicit file allowlist, not a cleaned whole-checkout copy. Any new generated result, local config, export, profile or log needs review before committing. A new Git history cannot revoke prior copies of the old public history.
